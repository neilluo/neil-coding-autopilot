# Observable Acceptance（可观测验收）— 单一事实源

> **谁引用**：`autopilot-explore`（Step 2/4）、`autopilot-analyze`（Step 3/4）、`autopilot-plan`（Task 的 `**Verify**`）。格式/判据/清单只此一份，各阶段一律「详见本文」不复制。
> **一句话**：user-facing 改动的验收，写成**不变量 + 蜕变关系（metamorphic relation）**，不写"期望等于几"的点 oracle——因为作者会把实现口径当期望写进去（test oracle problem），测试便把 bug 又确认一遍。

## 何时触发（user-facing 改动）
新增/改变任何**终端用户可直接观察**的输出：UI 渲染 / CLI·stdout / API 响应体 / 告警·通知内容 / 报表。（内部日志不属。）
- 纯内部重构 → **可证伪免除**：声明「无用户可观测变化」+ 列所核 surface + 断言未变；CR/verify 若发现 diff 触及上述 surface 层则免除作废、回炉补验收。

## 验收产物格式（对每个用户可观测值/态）
```
- 值/态：<名称>
- 权威源(SSOT)：配置 | 实测 | 派生（多源并存时，唯一权威源 = ?）
- 不变量(rule)：<普适规则，如"输出体现配置基数，与实测子集无关">
- 蜕变关系(MR)：固定权威源、扰动全部非权威源 → 可观测输出不变（或仍 = f(权威源)）
- 单源值：一句「单源：<源>，已排除候选源：<列举 + 为何不可能供值>」
```
- **禁实现口径（WARN，非阻塞）**：验收禁出现内部变量名/数据结构/算法（"数 X 的 key""取最新桶"）。判据：换一种实现写法，验收仍成立 = 合格。出现即 WARN、analyze 自检轮内自修，**不 BLOCK**。
- **判别力（硬要求）**：多源值必须给出**判别性样例**——两候选源产出**不同期望**（或明确"声明不变"且扰动确打在会分歧的轴上）。happy-path-only / 实现口径式验收给不出判别样例。

## 12 问（采集前端；产物 = 上面的 SSOT + 不变量 + MR）
1. 可见值清单：哪些用户可观测输出新增/变了？逐个列。
2. 来源 + **权威源(SSOT)**：实时/配置/派生？多源以谁为准？
3. **不变量（禁实现口径）**：普适规则，非"代码怎么数"。
4. 配置对得上：用户填 N，输出体现 N，不被实测覆盖。
5. **蜕变关系**：固定权威源、**扰动须覆盖全部非权威源**（≥2 源逐轴扰动，防"扰错轴假过"）；双向集差各给样例。
6. 基数与集合：0/1/N/超大量？顺序？重名？**聚合/合计项是否计入判别量？分子分母口径一致否？**
7. 状态细分：进行中 / 无数据 / 失败·超时 / 部分 各输出什么 + 恢复？
8. 时序并发：刷新时机、时间窗、陈旧、保存与测量竞态、多人同改？
9. **不变量测试**：MR 写成**确定性/内存态/离线**的扰动断言 = 该 Task 的 `**Verify**`（单命令指向测试目标）。
10. 连带影响（读+写+迁移）：别处读/写同一数据？迁移？改他人口径？回归范围？
11. 非功能 + 权限：性能、i18n、可访问性；各角色/租户值都对吗？
12. 上线可观测 + 未决登记：自动化测试守护？埋点能否发现复发？`[NEEDS CLARIFICATION]`。

## 判定与落地
- **结构门（阻塞·确定性）**：user-facing 改动**既无验收段、又无可证伪免除** → `{ANALYZE|PLAN}_STATUS=BLOCKED|{原因}`（立即 exit，禁挂起）。仅此一种阻塞（确定、罕见、无人值守安全）。
- **覆盖/口径（非阻塞·自愈）**：MR 缺失/无判别力/口径泄漏/三态缺 → analyze=WARN 自修；运行期由 §「验证」的扰动测试在**既有 verify 门**直接拦（buggy 必挂 → 既有 fixer 循环自动修）。
- **oracle 独立性**来自「不变量在实现前已冻结」：不变量/扰动轴/期望由 spec/tasks（设计期）固定；可执行测试文件因 controller write-gate 只能由 worker 落地。独立性靠"MR 先于实现冻结"，非靠"谁敲测试文件"。

## 验证：蜕变测试即 `**Verify**`（不动脚本）
- plan 为 user-facing Task 写的 `**Verify**` 必须是上面的**确定性扰动测试**（`run-track-a.sh` 现成 `eval "$verify"` 执行 → 无人值守直接拦，无需改脚本）。**禁**仅编译级 Verify。
- **多数"显示"bug 的计数/派生在后端、可离线被 MR 抓**（主战场）；只有**纯像素/DOM 渲染层**无离线宿主。

## 不可离线验证 & Phase 2（诚实边界，不 overclaim）
- 无离线宿主的**纯渲染**值：Task 打 `UNVERIFIED-OBSERVABLE(<MR>)` + 登记 `clarifications.md` + 变更摘要醒目列出。**诚实说明**：脚本不识别该标记、loop 不读 clarifications，故 **headless 下仍 commit DONE**——**书面响亮登记、非运行期拦截**（靠 Phase 2/人读产物兜），但不 stall、不烧钱、不冒充"已验证"。
- **本门不保证**（设计门固有上限，交 Phase 2「观测/独立 QA 层」兜）：
  - (a) novel 且 **SSOT 选错**：自洽错 MR 过全部结构门（reviewer 交叉核验默认关）。
  - (b) 纯渲染层无离线宿主：见上（headless 非运行期拦）。
  - (c) 多源**扰动轴不完备**：只扰无关源则假过（Q5 要求逐轴扰动压低，但无机检）。
  - 附：确定性但**写错的 MR** 可能令正确实现翻 FAIL → fixer≤MAX_ROUNDS→exit2（有界假停线）；极少数下 fixer 亦可能改坏正确码去迎合错测试 → 静默提交坏码。靠"MR 设计期冻结 + Q5 逐轴 + §可选交叉核验"压低。
- 定级：**让决策显式可执行 + 最大化拦截 + 缺口响亮可见**，非"必然堵死"。本文产物即 Phase 2 的输入契约。

## Worked example（通用示意，非项目专属）
- 值：某"集合计数"展示；SSOT=配置；非权威源=实测子集 M⊆配置。
- 不变量：显示数 = |配置集合|，与 M 无关。
- MR（确定性/内存态）：固定配置 N=2，扰动 stub 实测 M=（2→1→0）→ 断言显示恒=2。buggy（数实测）给 2/1/0 → 违反 → 抓。
- 聚合项：判别量须**排除合计/通配项**（如把通配 `*` 混入分子会令超阈计数 k 跳变、致"1/3"类误导）——扰动"结果集是否含通配项"→ 断言 k 不变。
