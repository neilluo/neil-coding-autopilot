| SF-06 | **B** | 自动刷新可暂停或可调频率 |

| SF-08 | S | 重要失败不用 3s 自动消失的 message，用 Modal/Alert 常驻 |
| SF-09 | S | 错误文案 = 现象 + 原因 + 下一步；不裸露堆栈/错误码 |

## C. 数据可读性与正确性（16 · 差异化核心）

| ID | 级 | 断言 |
|---|---|---|
| DT-01 | **B** | 缺失/null 绝不渲染为 `0`：表格 `-`、无数据 `--`、图表断点不连线 |
| DT-02 | **B** | 聚合口径不因 UI 改动而变（求和/均值/去重/时区） |
| DT-03 | **B** | 数值精度不因显示格式丢失（展示截断、导出用原值） |
| DT-04 | S | 表格中数值列右对齐 |
| DT-05 | S | 用于比较的数字用等宽 `font-variant-numeric: tabular-nums` |
| DT-06 | S | 大数字有千分位；单位与数字规范且全站统一 |
| DT-07 | S | 绝对时间 `YYYY-MM-DD HH:mm:ss`（24 时制）；区间用 ` ~ `（前后空格） |
| DT-08 | N | 相对时间遵循阶梯（刚刚 / N 分钟前 / N 小时前 / MM-DD HH:mm / YYYY-MM-DD HH:mm） |
| DT-09 | S | 时间必须标注时区/口径（尤其跨天/跨零点的日报） |
| DT-10 | S | 图表类型与数据语义匹配（趋势→线/构成→饼堆叠/分布→直方/对比→柱） |
| DT-11 | S | 默认不堆叠；如需堆叠必须显式说明 |
| DT-12 | N | 不同单位/量级用双 Y 轴或拆图；量级差不掩盖小值 |
| DT-13 | N | 比率类指标归一化（用百分比而非受分母影响的绝对值） |
| DT-14 | S | 每个指标名旁有口径解释（Popover/description），不依赖外部文档 |
| DT-15 | N | 高度聚合的图必须能补充细节（下钻/hover 明细/切粒度） |
| DT-16 | S | 极端内容不破版：超长 ID 截断 + tooltip 全文、超大数不换行、空数组不渲染残缺骨架 |

| A11Y-09 | S | UI 组件/状态/图表关键图形对比度 ≥ 3:1 |
| A11Y-10 | **B** | 状态不只用颜色表达（告警三态 = 色 + 图标 + 文字） |

| A11Y-12 | S | 原生语义优先（button/a/label/table），不用 `<div onClick>` |
| A11Y-13 | S | 标题层级不跳级、唯一 `<h1>`；提供 skip link |
| A11Y-14 | S | Tabs 符合 APG（tablist/tab/tabpanel + aria-selected + 方向键循环） |
| A11Y-15 | S | Modal 符合 APG（外部 inert、Tab 循环、Esc 关、焦点入内/归还） |

## G. 一致性与视觉体系（8）

## H. 性能与交互体感（8）

| ID | 级 | 断言 |
|---|---|---|
| PF-01 | S | 关键交互 INP ≤ 200ms（>500ms 视为 P0） |

| PF-03 | N | 动画只动 `transform`/`opacity`；禁止 `transition: all` |
| PF-04 | S | 尊重 `prefers-reduced-motion` |

| PF-07 | N | 无图片导致的 CLS（显式宽高）；图表容器预留高度 |
| PF-08 | P | 频繁刷新的图表复用实例（ECharts `setOption`，谨慎 `notMerge`） |
